# Shroom and Gloom — Traduction française (mod non officiel)

> **Pourquoi ce projet ?**
> J'adore *Shroom and Gloom*, et je voulais simplement pouvoir y jouer **en français**.
> C'est tout : un projet de fan, gratuit, fait par passion, sans aucune autre ambition.

## ⚠️ Mention importante

**Shroom and Gloom et tout son contenu (jeu, code, univers, personnages, noms, textes originaux,
graphismes, musiques, marques) restent l'entière propriété de leurs développeurs, [Team Lazerbeam](https://store.steampowered.com/search/?developer=Team%20Lazerbeam).**

- Ce mod est **non officiel**. Il n'est ni affilié à Team Lazerbeam, ni approuvé ou soutenu par le studio.
- Il ne contient **aucun texte original du jeu** : uniquement la traduction française (dans un fichier de langue
  au format du jeu) et des scripts d'installation. Il faut posséder le jeu (sur Steam) pour l'utiliser.
- Il est distribué **gratuitement** et ne doit pas être vendu.
- Si les développeurs souhaitent que ce dépôt soit modifié ou retiré, **je le ferai sans discuter** :
  il suffit d'ouvrir une *issue* ou de me contacter.

Si le jeu vous plaît, soutenez les développeurs en l'achetant et en en parlant autour de vous ! 🍄

## Ce qui est traduit

Environ **2 900 textes**, soit tout ce que le jeu affiche :

| Partie | Textes |
|---|---|
| Noms de cartes | 964 |

*Foresight* = **Prémonition**, *Decay* = **Pourriture**, *Toasty* = **Croque**. Le jeu tutoie le joueur.
Le glossaire complet est dans [`traductions/GLOSSAIRE.md`](traductions/GLOSSAIRE.md).

## Installation

> ⚠️ **Avertissement de Windows au premier lancement**
> Comme le fichier vient d'Internet, Windows peut afficher « Windows a protégé votre ordinateur ».
> Le joueur clique sur **« Informations complémentaires »**, puis sur **« Exécuter quand même »**.
> C'est normal pour tout fichier téléchargé qui n'est pas signé numériquement.

1. Télécharge **[ShroomAndGloom-Traduction-FR-v1.0.zip](https://github.com/marvinleeroy/ShroomAndGloom-Traduction-FR/releases/latest/download/ShroomAndGloom-Traduction-FR-v1.0.zip)**
   (ou depuis la page [Releases](https://github.com/marvinleeroy/ShroomAndGloom-Traduction-FR/releases)).
2. Décompresse-le dans le dossier du jeu
   (Steam → clic droit sur le jeu → *Gérer* → *Parcourir les fichiers locaux*).
   Tu obtiens un dossier **`ShroomAndGloom_ModFR`**.
3. **Ferme le jeu**, puis double-clique sur **`installation_traduction_fr.bat`**.
4. Lance le jeu → **Settings → Language → French (fr)**.

Après une mise à jour du jeu par Steam, relance simplement `installation_traduction_fr.bat`.

### Désinstallation

Double-clique sur **`desinstallation_traduction_fr.bat`** : les fichiers d'origine sont restaurés à l'identique.
En dernier recours : Steam → *Propriétés* → *Fichiers installés* → *Vérifier l'intégrité des fichiers du jeu*.
